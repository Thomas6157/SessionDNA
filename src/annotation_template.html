Donner un sens aux séances, une à une
Décrire la séance avec tes catégories sportives

1. Objectif principal : choisis l'objectif de l'effort réalisé, à partir de ton programme et de ton souvenir. Récupération, footing/EF, endurance soutenue, seuil, VO₂max, vitesse/sprints ou compétition. Si la séance s'est éloignée du programme, indique-le dans la note. La vitesse seule ne permet pas de certifier une zone physiologique.

2. Format : continu, progressif, intervalles courts ou longs, mixte. Pour garder une convention commune, « longs » désigne ici des efforts d'environ deux minutes ou plus ; « courts », moins de deux minutes. Ce repère décrit la durée, pas l'intensité.

3. Caractéristiques : sortie longue selon ton programme et ton contexte ; brick run si course enchaînée après le vélo ; côtes si elles font partie du travail prévu. Choisir Oui, Non, Incertain, ou laisser non renseigné.

Exemples : seuil long → Seuil + Intervalles longs ; sortie longue facile → Footing/EF + Continu + Sortie longue : Oui. Une brick run peut avoir n'importe quel objectif. Une pause de montre au milieu d'un effort n'est pas une nouvelle répétition.

Choisis Incertain plutôt que de deviner. Les tags non renseignés ne sont pas des réponses Non. Les anciennes annotations restent accessibles, mais elles ne donnent pas automatiquement le nouvel objectif.
